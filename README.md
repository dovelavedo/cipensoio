## Lettore Poker

In `poker/` c'è un lettore vocale per tavoli di poker a fiches virtuali, pensato per chi è ipovedente: annuncia in tempo reale le proprie carte, le carte sul tavolo, il piatto, le puntate e la posizione. Guarda la scheda di gioco tramite la condivisione schermo del browser (Chrome o Edge su computer), non clicca nulla e non invia dati.
